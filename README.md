# Портфолио, v1

Сайт: https://nightroadman.github.io/portfolio/ (GitHub Pages, ветка `main`, корень).

Одна страница без сборки.
поэтому двойной клик по `index.html` не сработает — нужен локальный сервер:

```bash
cd ~/Portfolio
python3 -m http.server 8000
# открыть http://localhost:8000
```

Контент временный (проекты, компании, цифры выдуманы). Он лежит в массиве `projects` в скрипте внизу `index.html`.

## Мозг

- `brain/brain-hero.js` — собранный модуль BrainTM (`prototype/dist/brain-hero.js`), `brain/data/` — его данные.
- Монтируется в `#brain`: на десктопе липкая колонка справа, на ширине < 768px — полоса под шапкой.
- Скролл по списку проектов ведёт аксиальный срез сверху вниз: страница шлёт событие `brain:slice`
  с `{ index, total, year, id, progress }`, модуль-скрипт внизу страницы переводит `progress` в `hero.setSlice()`.
- Фон страницы `#050807` совпадает с цветом очистки canvas, поэтому рамки вокруг мозга нет.
- В `brain/brain-hero.js` добавлена опция `--brain-fit` (CSS-переменная на `#brain`): какую долю колонки занимает мозг.
  Шкала срезов перенесена вправо, подпись Axial и кнопка Reset скрыты стилями страницы.
- Если пересобрал BrainTM, замени свой `prototype/src/brain-hero.js` на `brain/brain-hero.src.js` (там та же правка `--brain-fit` в `resize()`), собери, скопируй новый `dist/brain-hero.js` и `data/` сюда.
